🌌 Symmetry & Degeneracy

in 2D Quantum Wells

📚 View on GitHub 📊 Open Interactive Demo

🎯 What This Shows

How exchange symmetry in a square well creates degeneracy, and how deforming to a rectangle breaks that symmetry.

🎚️ Interactive Control

Adjust the aspect ratio slider to see energy levels split in real-time. Watch as symmetry breaks.

📈 Visualizations

Energy diagrams, splitting curves, and degeneracy tables—all computed dynamically in your browser.

To run the interactive demo:

npm install && npm start

The widget will open in your browser at http://localhost:3000
